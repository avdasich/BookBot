# BookBot

[English version](README.md)

BookBot — простое консольное приложение на Python для анализа книг и получения статистики по тексту.

## Возможности

- Подсчёт общего количества слов в книге.
- Подсчёт частоты появления символов без учёта регистра.
- Сортировка символов по частоте встречаемости.
- Формирование отчёта со статистикой слов и букв.
- Анализ разных текстовых файлов через аргументы командной строки.

## Установка и запуск

Клонируй репозиторий:

```bash
git clone https://github.com/avdasich/BookBot.git
cd BookBot
```

Запусти программу, указав путь к книге:

```bash
python3 main.py books/frankenstein.txt
```

Для анализа других книг:

```bash
python3 main.py books/mobydick.txt
python3 main.py books/prideandprejudice.txt
```

## Принцип работы

BookBot считывает текстовый файл, подсчитывает количество слов и частоту появления каждого символа.

Затем программа сортирует символы по количеству повторений и формирует отчёт. В итоговом отчёте отображаются только буквы, от наиболее частых до самых редких.
